# Recetario Digital

Recetario Digital es una página web desarrollada como proyecto
de Programación Estructurada.

Su objetivo es permitir que las personas puedan consultar,
buscar y agregar recetas de cocina desde un mismo lugar.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Supabase
- GitHub
- Vercel
- Visual Studio Code

## Funcionalidades

- Visualizar recetas.
- Agregar nuevas recetas.
- Buscar recetas por nombre.
- Filtrar por categorías.
- Consultar ingredientes.
- Consultar preparación.
- Almacenar información en Supabase.

## Categorías

- Comidas
- Postres
- Desayunos
- Bebidas
